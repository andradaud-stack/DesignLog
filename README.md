# DesignLog V2 — Intern Archival Ledger (2026)

**DesignLog V2** is the curated digital repository and portfolio ledger for graphic design residency deliverables formulated for **Hotel Horison Inn Antawirya Semarang** and **Hotel Horison Resort Antawirya Jepara** under **PT Metropolitan Golden Management (MGM Corp)** in collaboration with **Universitas Dian Nuswantoro (UDINUS)**.

---

## ✨ Features & Capabilities

1. **Dashboard**
   - Live KPI cards: Total Output (48), Current Month (11), Horison Semarang (26), Horison Jepara (22).
   - Dynamic Property Scope Filter: Instant toggle between Semarang (Urban Business) and Jepara (Coastal Resort).
   - Internship Progress Tracker: Day 24 of 92 (26% elapsed) with milestone markers.
   - Dual-Property Distribution Bar (54% Semarang vs 46% Jepara).
   - Deliverables by Category progress breakdown (8 taxonomy dimensions).
   - Recent Works Gallery with hover zoom and quick inspection.

2. **My Works (Portfolio Gallery)**
   - 48 fully audited design artifacts with authentic high-resolution imagery and specifications.
   - Dual layout modes: **Grid View** (with aspect ratios: 1:1, 3:4, 16:10, 4:5) and **List View**.
   - Keyboard shortcut: <kbd>⌘</kbd>+<kbd>K</kbd> / <kbd>Ctrl</kbd>+<kbd>K</kbd> instant search focus.
   - Multi-tier filtering: Period, Hotel, Category, and Status pills.
   - Active filters ribbon with quick dismiss tags and "Clear All".
   - Sort by Newest Release, Oldest Release, Recently Added, and Property.
   - Quick action buttons on card hover: View Case Archive, Edit Metadata, Download Asset Package.

3. **Statistics & Analytics**
   - Operational Ledger & Velocity Metrics (3.8 designs/wk, 91.6% first-pass pass rate, 1.4 avg revision depth).
   - Dual-Property Comparative Output Analysis (format split, review cadence, deliverable profiles).
   - Category Breakdown across 8 dimensions with stacked comparative bars.
   - Chronological Cadence Histogram (Apr–Dec 2026 timeline with seasonal peaks).
   - Cohort Matrix Comparison (Cohort I Completed vs Cohort II In Flight).
   - Workflow Status breakdown (Final 41, Revision 4, In Progress 2, Draft 1).
   - Archival Spotlight showcases.

4. **PDF/X-1a Pre-Press Inspection & Proofing Modal**
   - Accessible via **"Export Analytics PDF"** in Statistics.
   - Dual-page facing spreads viewer (Spread 1: Front Archival Cover & Curatorial Brief; Spread 2: Semarang & Jepara Case Spotlights).
   - Interactive zoom controls (75%–130%), Fit Width, and Focus Mode.
   - Pre-Flight Certification Checklist (Raster assets ≥ 300 DPI, CMYK FOGRA39 profile, 3mm bleed, outlined typography).
   - Detected Brand Color DNA dock (`#1B2B34`, `#BAA479`, `#A73918`, `#2B4C7E`).
   - Print proofing and export simulation.

5. **Release Calendar**
   - Visual release calendar for October 2026 (and historical months).
   - Daily event pills color-coded by hotel.
   - Date precision dimension management:
     - Exact timestamped records.
     - Month-only historical precision (e.g. Eid Mubarak Greeting Semarang).
     - Cohort-span window records (e.g. F&B Menu Insert Jepara).
     - Date unknown archives (e.g. Poolside Live Music Poster).

6. **Internship Periods & Hotels Profiles**
   - Cohort I (Apr–Jun 2026) and Cohort II (Oct–Dec 2026) roadmap.
   - Dedicated hotel brand identity sheets, color palettes, and operational focuses.

7. **Deliverable CRUD Operations**
   - **+ Add Work** modal with live image preview and celebration confetti.
   - Edit metadata and delete actions.
   - LocalStorage persistence and backup export/restore.

## 🚀 Getting Started

### Development Mode

Run the local Vite development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build & Preview

```bash
npm run build
npm run preview
```
